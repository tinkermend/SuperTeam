现状 7 个语义色来源混杂，明度 54.6–65.8、饱和度 0.136–0.242，并排使用时轻重不一。提案在 OKLCH 中固定 L=0.60 / C=0.15 只转色相派生全家族，并为每个语义色增加深两档的文字层，让 soft 底上的文字全部达到 WCAG AA（≥4.5:1）。品牌蓝 #2F5FFF 保持不动。

09随色板一起生效的使用规则（写入 DESIGN.md）

  • 状态色词表：ok / warn / danger / mute 只允许出现在 StatusPill、状态圆点、accent bar、V3Tr tone；类别图标（IconTile）默认 mute 或 brand-soft，不再按实体换色。
  • artifact 紫只表示「工件」这一个类别，退出状态词表。
  • info 的取舍：迁到青色后保留；若后续实践中仍与 mute 职责重叠，可直接并入 mute（本页展示保留方案）。
  • 彩色文字只保留两种：链接 / 主操作（brand）与 danger 警示；「成功 · 7 小时前」类元信息一律灰字 + 前置语义圆点。
  • 每屏语义色预算：一行 / 一卡最多 1 个语义色状态编码；KPI / 图标带同屏最多 2 种非灰色调。
  • 顺手修：capabilities/index.tsx:8 的 tone="warning" → "warn"（现为静默无样式）。
