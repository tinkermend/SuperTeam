本轮已吸收的设计约束

  1. 顶栏仅 4 区段：工作台 / 任务 / 审批 / 资产；配置不进对等 Tab
  2. 事件流 = 任务执行记录 + 任务审批记录（创建/通过/驳回等）
  3. 运行脉搏每条带 时间 + Plan/Loop/对话模式
  4. 空态：启动卡 + 单行空态（禁止巨卡 V3EmptyState）；宽屏用媒体查询双栏，不依赖未挂载的 master-detail 容器
  5. 布局目标：尽量少滚看完首屏，非强制一屏；溢出用侧栏内滚 / Tab 跳出
  6. 全量信息不堆首屏：用「查看全部…」跳到任务 Tab / 收件箱 / 审计
