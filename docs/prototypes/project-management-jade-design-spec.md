# Jade Garden 设计规范

> **柔彩卡片风 · 翡翠绿系 · 友好圆润**
> SuperTeam 项目管理页面视觉焕新方案 v2

---

## 设计理念

**"Jade Garden"** 是一个温暖、友好、不严肃的亮色设计语言。它抛弃了传统控制台的冷峻感和深色科技感，转而用**柔和的分区色彩、圆润的形状、翡翠绿的信任主线**，让 AI 任务管理界面像一座精心打理的花园——每个区域有自己的色彩呼吸，整体和谐统一。

与现有 v3 Soft-Flat（浅蓝硬边）和 Quantum Command（深色玻璃态）完全不同，Jade Garden 追求的是**亲和力与专业感的平衡**。

| H2 | 18px | 700 | 1.3 | 区段标题 |

**字体族**：

## 间距与圆角

### 间距（8pt 基准）

```
4 · 8 · 12 · 16 · 20 · 24 · 32 · 48 · 64
```

卡片内边距 20-24px，卡片间距 12-16px，区段间距 28-32px。

### 圆角

| Token | 值 | 用途 |
|---|---|---|
| `--r-sm` | 8px | 小标签 |
| `--r-md` | 12px | 导航项 / 图标按钮内框 |
| `--r-lg` | 16px | 中型卡片 |
| `--r-xl` | 20px | 项目卡片 / 风险卡 |
| `--r-2xl` | 24px | 空状态 |
| `--r-full` | 9999px | 按钮 / 胶囊 / 头像 |

**设计原则**：Jade Garden 大量使用全圆角（pill）按钮和 20px 大圆角卡片，营造柔软友好的视觉感受。

## 阴影体系

多层柔影，带翡翠绿色调，避免生硬黑影：

```
--shadow-xs: 0 1px 2px rgba(6, 78, 59, 0.04)
--shadow-sm: 0 1px 3px rgba(6, 78, 59, 0.05), 0 1px 2px rgba(6, 78, 59, 0.03)
--shadow-md: 0 4px 12px rgba(6, 78, 59, 0.06), 0 2px 4px rgba(6, 78, 59, 0.04)
--shadow-lg: 0 10px 28px rgba(6, 78, 59, 0.08), 0 4px 10px rgba(6, 78, 59, 0.05)
--shadow-emerald: 0 4px 14px rgba(16, 185, 129, 0.25)
```

主按钮使用 `--shadow-emerald`（翡翠绿光晕），悬停时光晕加深。

## 组件模式

### 1. 风险概览 Bento

四张柔色卡片，每张拥有独立的分区背景色（薄荷绿 / 奶油黄 / 暖桃 / 雾紫），右上角有装饰性圆形色块。点击可快速筛选对应风险等级。

**关键细节**：
- 36px 大数字，字重 800
- 趋势箭头（↑ 绿 / ↓ 红 / — 灰）
- 悬停上浮 3px + 大阴影

### 2. 筛选胶囊（Filter Pills）

全圆角胶囊按钮，激活态使用翡翠绿渐变 + 绿色光晕。风险筛选胶囊激活时变为对应语义色（橙 / 红 / 紫）。支持互斥切换。

### 3. 项目卡片

**不使用表格**，改用全宽圆角卡片列表。每张卡片包含 5 列网格：

1. **项目身份**：名称 + Mono ID 标签 + 描述 + 负责人头像
2. **当前任务**：任务名 + Runtime 节点状态点
3. **处理者**：彩色徽章（人工=奶油黄 / AI=薄荷绿 / 空闲=灰）
4. **状态**：柔色状态胶囊 + 原因说明
5. **进度**：百分比 + 翡翠绿进度条 + 最后运行时间

**左侧 4px 风险色条**：低=绿 / 中=黄 / 高=红 / 严重=深红，悬停加宽至 5px。

### 4. 状态胶囊

软底色 + 实心圆点 + 700 字重文字。运行中和等待状态的圆点有 `pulse-soft` 呼吸动画（2s 周期，缩放 + 透明度变化）。

### 5. 按钮

- **Primary**：翡翠绿渐变 + 绿色光晕 + 悬停上浮
- **Secondary**：白底灰边 + 悬停变薄荷底绿字
- **Ghost**：透明 + 悬停薄荷底

全部使用全圆角（pill shape），高度 42px。

## 动效

| 场景 | 动效 | 时长 |
|---|---|---|
| 卡片悬停 | translateY(-1px) + 边框变绿 + 阴影加深 | 220ms |
| 风险卡悬停 | translateY(-3px) + 大阴影 | 220ms |
| 状态圆点呼吸 | scale(0.85) + opacity(0.5) | 2s infinite |
| 进度条填充 | width 渐变 | 360ms |
| 筛选切换 | 即时 + 重新渲染 | — |

所有动效遵守 `prefers-reduced-motion: reduce`，降级为瞬时切换。
