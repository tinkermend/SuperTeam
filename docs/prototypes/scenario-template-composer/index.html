新建场景模板 · 原型索引

功能模型：自定义任意多站，每站分派一个剧本角色（席位，不绑人）；标了「可作出口」的站，发起任务时可选深度停在那里。下面三套贴合项目 Soft-Flat 设计基线（近白冷灰底 + 白卡弥散阴影 + 品牌蓝强调 + 玻璃只做低密度外壳）。

Soft-Flat 三方案（当前）

方案一 · 关卡链 + 检修台

链是主角，表单只服务当前站

顶部横向关卡链（节点母题），点一站在下方检修台编辑；右侧玻璃卡放约束摘要与深度模拟。最直观。

 方案二 · 主从编排台

队列 + 详情 + 发起预览表

左列站队列（含出口/人类门徽标），右侧编辑选中站；下方脆数据面表格逐行预览发起时的深度选项。信息密度最高，最贴现有工作台惯例。

 方案三 · 词表画布

点角色 → 点接收位，即分派

左栏角色词表常驻（带在编人数），中间竖向节点画布沿主轴生长，右侧玻璃摘要。分派动作最轻，适合角色多的租户。
与任务发起的关系：模板作者声明哪些站「可作出口」；发起人之后只在这些出口里选深度（五站模板这次可以只跑到「定界」）。三套原型的深度模拟均按此实现，站数均不封顶，默认演示为运维故障处置，可切运维分析 / 软件交付 / 空白。
落地方案：正式重构设计稿见 redesign-spec.md——以方案二为骨架、方案一链条压缩为顶部只读概览条，全页路由取代弹窗，含 spec-composer 映射扩展与分阶段计划。
