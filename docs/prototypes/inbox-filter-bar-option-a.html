方案 B · Chip 标签式筛选（Linear / Vercel 风）
· 三个高频筛选是 V3Chip：默认态为白卡描边（空心），选中具体值后变 实心品牌蓝。
· 三个筛选都有中性态「所有 / 全部」：状态 默认「开放」(实心)，可切换到「所有」(空心) 展示全部状态；类型 / 风险 默认「全部」空心。选中具体值后出现 ✕ 可一键清除回中性态——✕ 对每个 chip 都有效。
· 后端需将 status 改为可选参数（缺失或 all 时返回所有状态），前端已支持 delete filters.status。
· 两个 UUID 输入收进 「更多筛选」，日常视图只留 3 个高频 chip，工具栏更干净；填入值后「更多筛选」显示数量徽标并激活。
· 点击任意 chip 可展开下拉；点击外部或按 Esc 关闭。
