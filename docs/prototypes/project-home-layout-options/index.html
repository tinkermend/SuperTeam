SuperTeam · 本地原型

项目管理首页，两条明确的工作路径

不是把现有 KPI、项目表和右栏重新排版，而是让首页先服务“人现在要不要做决策”或“运营现在该先看哪个项目”的不同目的。

当前问题

同一屏同时承担决策、扫读与运行回顾

现状的“待我决策”在指标卡、项目行和右侧导轨重复出现；而项目生命周期、任务执行和人类决策又是不同层级，不能压成一个笼统状态。

首页只导流审批仍在收件箱或项目详情完成。
层级不混用生命周期、执行进展、人工信号分别表达。
表格仍是实底密集扫读不放入玻璃或装饰卡。
对象先于标识列表始终先显示项目名、当前动作和时间。

决策优先工作台

首屏先给负责人一个可快速清空的决策工作面，再给需要介入的项目队列。

  • 主对象：待我决策与阻塞动作
  • 适合：负责人日启、决策积压明显
  • 代价：完整项目比较放到第二屏

组合检视工作台
