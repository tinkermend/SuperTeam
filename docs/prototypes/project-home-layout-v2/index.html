项目管理首页 · 三套布局方案

基于当前「KPI 五卡 + 项目队列 + 右栏待我决策/运行动态」现状，结合 DESIGN.md（脆数据面、工作对象规则）与 项目域模型（Project 闭环容器、人类一等、风险/决策信号分层），给出三种信息架构不同的布局方向供选择。

数据口径沿用现网 mock/真值 队列 / 决策 / 运行动态 三维度保留 首页只导流 · 不在列表执行审批 禁止玻璃套密集表

现状问题 ① 纵向过重

五张等高 KPI + 双栏主从，决策（最可行动）与队列争抢视线；首屏有效行数偏少。

现状问题 ② 状态双轨

业务状态（验收中/已就绪）与注意力信号（待决/证据/超时）挤在「待办拆分」一列，扫读成本高。

现状问题 ③ 角色未分层

负责人「先决策」与运营「先扫队列」是不同主路径，现状用同一骨架兼顾，两边都不够极致。
