SuperTeam 侧边菜单视觉探索

背景要高级，但更关键的是让导航像控制平面。

当前截图的问题不只是底色平。菜单项、分组、激活态和底部账号区都在同一层级上，品牌识别主要靠蓝色文字。 下面的四个方向都保留 v3 Soft-Flat 的浅色、蓝色主强调和 236-248px 导航密度，只改变壳层背景、状态表达和菜单组织。

环境层用低对比网格、冷灰 wash 和玻璃面提升质感。
当前位置激活态加左侧锚点、柔蓝底和稳定计数。
分组节奏标题更轻、间距更克制，降低长菜单疲劳。
账号区从普通按钮变成身份与节点状态的小面板。

截图里的可优化点

1
背景太像默认浅灰缺少 SuperTeam 的“节点、网络、中枢”母题，右侧边缘也没有壳层深度。
2
激活态信息少只有大块柔蓝底，未明确告诉用户“当前位置”还是“待处理状态”。
3
图标和文字过重图标、标题、菜单文字尺寸接近，长列表扫读会显得笨重。
4
底部账号区被截断账号卡需要固定高度、清晰层级和邮箱省略策略，避免遮挡菜单。
方向 A · Acrylic Shell

最稳的高级感：保持现有结构，升级背景和激活态。

这是最接近当前产品的方向。它用轻玻璃白面、冷灰渐变和柔和右侧阴影提升质感，但菜单密度、分组顺序和当前视觉纪律都不大改。

适合直接落地对现有 shadcn sidebar 改动小，风险最低。
选中态更像定位柔蓝底保留，增加 3px 品牌色竖条和细边框。
账号区收成白面卡头像、姓名、邮箱和展开入口明确分层。
建议：如果目标是“先让现在的菜单变高级”，优先用 A 做第一版。

方向 B · Topology Grid

更有平台识别度：把“矩枢”的网络语言放进侧栏。

这个方向最强调“控制平面”。背景不是普通渐变，而是低对比节点网格。选中项像被路由选中的节点，适合让产品从普通后台变成 AI 调度平台。

品牌母题更强节点、细线、柔蓝路径构成专属识别。
状态和位置分离当前位置用节点锚点，数字角标仍表达待处理数量。
底部加入运行信号账号区带 Runtime/Provider 健康摘要。
建议：如果你想让菜单“不像模板后台”，B 是最有辨识度的方向。

方向 C · Floating Workbench

更现代、更轻：侧栏像浮在 Shell 上的工作台。

这个方向比 A 更有空间感。侧栏不贴死页面边界，而是一个浮动玻璃面板；上方增加“发起任务”快捷入口，让菜单不只是导航，也像控制台的入口区。

高级感最明显浮动容器、玻璃边框和柔阴影形成更强层次。
适合大屏宽度略增到 272px，更适合展示快捷任务入口。
实现成本较高需要确认与现有 inset/floating sidebar 变体的兼容。
建议：如果未来要整体升级 Shell，C 可以作为更大胆的第二阶段。

方向 D · Dense Operator

最专业的后台感：压低尺寸，增强可扫读和运行摘要。

这个方向不追求明显玻璃质感，而是让菜单更像给高频使用者的操作台。它减少字号和行高，加入运行摘要，适合长期盯控和频繁切页面的人。

信息密度最高菜单项 36px 高，更接近专业控制台。
背景最克制白面实底，靠细线、摘要和激活锚点表达质感。
适合运维/管理人群底部账号区上方展示收件箱、审批、Runtime 摘要。
建议：如果你的目标是“长期使用不累、别太花”，D 的可用性最好。
