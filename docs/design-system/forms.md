# 表单

## 何时阅读

当修改 Input、Textarea、Select、Switch、Radio、Checkbox、表单布局、校验、只读/禁用状态，或弹窗/抽屉里的字段时，阅读本文件。

## 表单原则

- 可读性和操作效率优先于装饰。
- 不强行给表单加入装饰性渐变。
- 标题、说明、字段、错误和操作应形成清晰层级。
- 敏感信息、密钥和令牌默认脱敏展示。

## 控件

- Input、Textarea、Select、Switch、Radio 和 Checkbox 应保持统一高度、圆角、边框和焦点状态。
- 字段说明紧贴字段。
- 字段错误紧贴出错位置。
- 跨字段或业务规则错误放在分组顶部或提交区附近。
- 只读态和禁用态要可区分：只读表示可查看不可编辑，禁用表示当前不可操作。

## 弹窗与抽屉表单

- 表单字段、说明、辅助链接、上下文摘要和状态提示均为按需内容。设计系统只定义它们出现时的视觉方式。
- 不要求所有弹窗都有元信息或上下文面板。
- 弹窗中的 Textarea、Input、Select 使用稳定白色或强玻璃底、细蓝灰边框和主色 focus ring。
- 聚焦态可以有轻微青绿色 glow，但不能压住文字或降低可读性。
- 字符计数、帮助文字和只读说明应降低视觉权重。
- 字符计数应贴近字段底部或字段边缘对齐。

## 布局

- 相关字段通过间距分组，先用间距再用边框。
- 只有在间距和标签不足以区分层级时才使用分割线。
- 不要把每个字段都做成独立卡片。
- 长文本字段需要支持换行、展开或合理滚动。
- 按钮区在校验和 loading 期间应保持稳定。

## 校验与反馈

- invalid 状态应通过边框、文字、图标或错误信息表达。
- 必填标识应低调但清楚。
- 除非表单已提交或服务端数据本身无效，否则避免用户操作前就显示错误。
- 异步提交期间应禁用重复提交入口。
