# 导航

## 何时阅读

当修改侧栏、顶部栏、菜单、命令入口、Tabs、面包屑、工作区选择器或导航激活态时，阅读本文件。

## Shell 原则

Shell 是所有页面的视觉基准。新增功能页不得单独发明另一套侧栏、顶部栏、背景和选中态。

矩枢平台的导航与命令入口遵循 `visual-language.md`：导航降低颜色噪音，顶部搜索承担命令中心入口，品牌识别通过细线、节点、网格和选中态表达，不通过大量彩色图标或大面积渐变表达。

## 左侧导航

- v3 当前目标：保留现有左侧栏导航范式，不改成顶栏；Shell 大底使用 `--v3-bg` 中性冷灰，侧栏使用 `--v3-card` 白色实底 + `--v3-line`/`--v3-line-strong` 细分割 + `--v3-shadow` 弥散阴影。
- Shell 不使用偏色大面积背景、透明内容地基或内容区装饰光斑。
- 默认不使用大面积深色侧栏。
- 桌面展开宽度遵循当前 shadcn sidebar 体系，约 `236px` 到 `248px`。
- 折叠态只保留图标和必要状态。
- 右侧使用 `--v3-line-strong` 细蓝灰边框和 `--v3-shadow` 轻阴影，不使用厚重阴影。
- 菜单按工作区、编排、执行、治理等领域分组。
- 分组标题使用灰蓝色小字，降低权重。
- 菜单项高度约 `40px` 到 `44px`，圆角不超过 `12px`，图标列对齐，计数或状态点靠右。
- v3 激活态使用 `--v3-brand-soft` 柔蓝底 + `--v3-brand-deep` 蓝色文字/图标，不使用白字高饱和渐变块。
- Hover 使用 `--v3-card-soft`，不能改变布局尺寸。
- Footer 用户区保持紧凑，使用 v3 白面、细边框、打开态蓝色柔底；下拉菜单使用实底 `--v3-card`。

## 导航图标颜色

导航图标默认统一为蓝灰中性色，减少视觉噪音。业务类别通过图标形状、分组标题和文案表达，不通过每个菜单一个颜色表达。

- 默认图标：`--v3-mute` 或 `--v3-ink-3`。
- Hover：图标可提升到 `--v3-ink-2`，背景使用 `--v3-card-soft`。
- 当前选中项：图标和文字使用 `--v3-brand` / `--v3-brand-deep`，背景使用 `--v3-brand-soft`。
- 当前选中项可加左侧 3px 品牌色竖条，表达“当前位置”而不是装饰。
- 计数、告警、失败和阻断使用独立状态 Badge；不要把导航图标常态染成红色、橙色或紫色。
- 只有当菜单项自身正在承载真实异常状态时，才允许短暂使用 warn/danger 状态提示。

## 顶部栏

- 高度约 `64px`。
- v3 顶栏默认不铺整条实底，Header 容器保持透明并融入 Acrylic Shell 背景；只在吸顶滚动后按需出现轻量 `--v3-shell-glass` 兜底层，避免内容滑过时降低可读性。
- 只承载全局动作：折叠菜单、面包屑、全局搜索、环境、团队、通知、帮助和账户。
- 搜索框应是顶部视觉中心之一，并作为平台命令中心的入口。使用更强的 `--v3-shell-search`、`--v3-shell-search-border`、`--v3-shell-search-shadow` 和 `--v3-brand` focus ring，在透明 Header 上保持清晰层级。
- 搜索框左侧图标表达“命令 / 搜索 / 发起任务”的统一入口；快捷键 keycap 尺寸固定，不挤压 placeholder。
- 搜索聚焦态可以出现轻量品牌顶线、节点线或 ring，但不能改变控件尺寸。
- 环境、团队、主题、通知和账户按钮使用 v3 白/灰实底按钮。
- 状态点使用语义色。
- 通知、帮助、设置和账户按钮保持轻量。
- 吸顶时可以轻微增加模糊和阴影，但不要出现深色遮罩。

## Tabs

- 同一业务域下的页面应共享一个页面级页头和 Tab 容器。
- 页面级或模块级 Tab 使用 v3 项目级 Tabs 组件；组件不足时在 `components/superteam/v3-components.tsx` 扩展。
- Tab 容器使用 `--v3-card` / `--v3-card-soft` 实底。
- 激活 Tab 使用 `--v3-brand-soft` 柔蓝底、稳定边框和柔和阴影。
- 激活锚点使用 `--v3-brand`，必须贴近胶囊底部，不穿过中文文字。
- 中文长标签需要支持换行或横向滚动，不应压缩文字、改变行高或造成页面横向溢出。
- `apps/web/src/components/ui/tabs.tsx` 保持 primitive 层；SuperTeam Tab 视觉应沉淀在 `apps/web/src/components/superteam/`。
