# 导航

## 何时阅读

当修改侧栏、顶部栏、菜单、命令入口、Tabs、面包屑、工作区选择器或导航激活态时，阅读本文件。

## Shell 原则

Shell 是所有页面的视觉基准。新增功能页不得单独发明另一套侧栏、顶部栏、背景和选中态。

## 左侧导航

- 背景使用白色或近白色玻璃底，带极淡青绿/淡蓝衬托。
- 默认不使用大面积深色侧栏。
- 桌面展开宽度遵循当前 shadcn sidebar 体系，约 `236px` 到 `248px`。
- 折叠态只保留图标和必要状态。
- 右侧使用细蓝灰边框或玻璃高光，不使用厚重阴影。
- 菜单按工作区、编排、执行、治理等领域分组。
- 分组标题使用灰蓝色小字，降低权重。
- 菜单项高度约 `40px`，圆角不超过 `8px`，图标列对齐，计数或状态点靠右。
- 激活态使用蓝绿色液态胶囊或浅青绿玻璃背景，不使用大面积高饱和色块。
- Hover 使用更浅的蓝/青色表面，不能改变布局尺寸。
- Footer 用户区保持紧凑。

## 顶部栏

- 高度约 `64px`。
- 使用白色玻璃底和淡蓝灰底部分割线。
- 只承载全局动作：折叠菜单、面包屑、全局搜索、环境、团队、通知、帮助和账户。
- 搜索框应是顶部视觉中心之一，使用白色或玻璃底、淡蓝边框和主色 focus ring。
- 环境和团队选择器使用轻量玻璃按钮。
- 状态点使用语义色。
- 通知、帮助、设置和账户按钮保持轻量。
- 吸顶时可以轻微增加模糊和阴影，但不要出现深色遮罩。

## Tabs

- 同一业务域下的页面应共享一个页面级页头和 Tab 容器。
- 页面级或模块级 Tab 使用 `LiquidTabsList` 和 `LiquidTabsTrigger`。
- Tab 容器使用浅色液态玻璃。
- 激活 Tab 使用玻璃胶囊面板、稳定边框和柔和阴影。
- 蓝绿色底边流光可以作为选中锚点，但必须贴近胶囊底部，不穿过中文文字。
- 中文长标签需要支持换行或横向滚动，不应压缩文字、改变行高或造成页面横向溢出。
- `apps/web/src/components/ui/tabs.tsx` 保持 primitive 层；SuperTeam Tab 视觉应沉淀在 `apps/web/src/components/superteam/`。
