# 图标

## 何时阅读

当修改图标尺寸、图标颜色、语义图标容器、图标按钮或装饰性图标时，阅读本文件。

## 图标来源

优先使用 `lucide-react`，除非当前功能已有更具体且被项目接受的图标来源。线性风格应保持一致。

## 尺寸与重量

- 图标尺寸跟随所在层级：按钮、Badge、标题、列表项或导航项。
- 除非图标表达当前主要对象，否则不要让图标抢视觉中心。
- 导航图标通常为 `18px` 到 `20px`。
- 同一层级的图标线宽、饱和度和视觉重量保持一致。

## 颜色

- 普通导航、菜单和工具栏图标保持轻量，默认使用蓝灰中性色。
- 当前导航选中项才使用品牌蓝；真实告警、失败或阻断才使用语义状态色。
- 彩色图标可表达状态，但不再用“每个业务类别一个颜色”的方式表达模块分类。
- 红色仅用于危险、失败或阻断状态，不作为普通导航常态色。
- 避免强渐变、阴影或多色贴纸感图标。

## 图标容器

- 关键对象可以使用彩色圆角图标容器。
- 页面标题、面板标题和分组标题使用轻量小徽章。
- 指标卡、能力项和列表对象可以使用更强的语义图标块。
- 语义图标容器统一使用 `IconTile`，通过 Soft-Flat tone 表达领域或状态，不做装饰插画。
- 矩枢视觉母题里的节点、网络、中枢和调度优先通过线性图标、节点编号、细连线和低对比网格表达，不手绘新的复杂 SVG 插画。

## 可访问性

- 纯装饰图标应隐藏给辅助技术。
- 表达含义的图标必须配合文字、标签或可访问名称。
- 图标按钮必须有可访问名称和可见焦点态。
