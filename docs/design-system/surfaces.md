# 表面与质感

## 何时阅读

当修改页面背景、Shell 表面、玻璃质感、卡片、面板或整体视觉层级时，阅读本文件。

## 表面模型

SuperTeam 表面应保持明亮、冷静、稳定：

- 页面底色：近白或极淡冷色
- Shell 表面：白色或近白玻璃，叠加极淡青绿/淡蓝衬托
- 内容面板：可读的白色或稳定玻璃表面
- 悬浮层：更强一点的玻璃底和柔和阴影
- 高密度数据区：更高对比度，减少透明度

## 液态玻璃

液态玻璃用于提升现代感和层级，但不能降低可读性。

建议值：

- 背景：`rgba(255, 255, 255, 0.72)` 到 `rgba(255, 255, 255, 0.86)`
- 模糊：`backdrop-filter: blur(16px) saturate(1.15)` 到 `blur(24px) saturate(1.3)`
- 边框：`rgba(156, 242, 218, 0.44)`、`rgba(191, 219, 254, 0.55)` 或 `rgba(255, 255, 255, 0.82)`
- 阴影：优先使用 `0 16px 40px rgba(15, 23, 42, 0.06)` 或 `var(--superteam-shadow-low)`

玻璃质感可用于 Shell、导航、顶部栏、工作区选择器、搜索、菜单激活态、按钮、卡片和轻量浮层。

表格正文、长表单、日志、审计明细、代码和错误内容不应使用强玻璃透明效果。

## 背景

- 主内容区使用近白或极淡冷色，通常在 `#F8FBFF` 到 `#FFFFFF` 之间。
- Shell 可以带非常轻的冷色 wash 或低对比网格。
- 背景纹理不能影响表格、图表和表单的辨识度。
- 不要散落装饰性光斑、独立 orb 或 bokeh。

## 卡片与面板

- 面板用于组织页面结构，卡片用于承载独立信息单元。
- 避免把大页面切成过多装饰性卡片。
- 面板标题区应包含标题、必要说明和少量操作。
- 复杂操作应进入工具栏、菜单、抽屉或详情区。

独立功能卡片可以使用高级卡片质感：

- 极微弱对角渐变，例如 `bg-gradient-to-br from-background via-background/95 to-superteam-primary-soft/40`
- 细粒度内侧高光，例如 `ring-1 ring-white/60`
- hover 上浮，例如 `hover:-translate-y-1`
- 使用 `hover:shadow-[var(--superteam-shadow-mid)]` 的柔和阴影

高级卡片质感只用于真正独立的卡片对象，不用于每个行、字段或小分组。

## 复用表面组件

- `LiquidShell` / `.superteam-auth-shell`：登录页和控制台外层背景。
- `LiquidCard` / `.superteam-liquid-card`：通用玻璃卡片。
- `LiquidPill` / `.superteam-liquid-pill`：搜索框、Tab 容器、次要胶囊按钮、轻量筛选器和非状态型短标签。

## 检查问题

- 文本在表面上是否仍然清晰？
- 阴影是否表达层级，而不是显得厚重？
- 玻璃质感是否服务工作流，而不是装饰页面？
- 这是复用表面，还是单页 class 堆叠？
