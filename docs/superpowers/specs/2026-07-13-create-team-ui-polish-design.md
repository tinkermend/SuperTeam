# 新建团队 UI 打磨

日期：2026-07-13  
> 复核状态：基于CHANGELOG证据
范围：`apps/web` 新建团队向导（`/teams/new`）

## 问题

1. 「可加入的数字员工」与右侧已选列表只用通用 Bot 图标，未展示数字员工头像。
2. 「权限与设置」步骤已无实际配置项，仅为占位，增加多余点击。
3. 创建页 `max-w-6xl` 居中，大屏两侧留白过大，内容显得过窄。

## 方案

### 1. 数字员工头像

- 候选列表与「本团队人员预设」中的数字员工行，统一使用既有 `EmployeeAvatar` + `employeeAvatarAsset`。

### 2. 步骤收敛为两步

1. **配置团队**：身份（名称/slug/主题色/图标）与负责人、数字员工同屏  
2. **确认并创建**

删除空壳「权限与设置」；身份与成员不再分步，避免窄表单单独成页填不满。

### 3. 大屏布局

- 创建页吃满 `Main`；步骤 1 上身份卡 + 下成员双栏，内容密度足够支撑全宽。
- 步骤 2 确认页沿用既有 review。

## 非目标

- 不改创建团队 API / draft → payload 映射。
- 不重做团队详情页权限配置。
- 不做全宽贴边布局。

## 验证

- 定向：`create-team-page` 相关 vitest（步骤文案与创建流）。
- 浏览器：大视口打开 `/teams/new`，确认留白、头像、三步流程。
